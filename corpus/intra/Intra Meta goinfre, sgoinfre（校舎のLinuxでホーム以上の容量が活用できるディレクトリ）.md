# goinfre

#### goinfre, sgoinfre（校舎のLinuxでホーム以上の容量が活用できるディレクトリ）

# goinfre

Linuxのローカルストレージ上で自由に活用できるディレクトリ。goinfreに保存したファイルなどはその席からでしかアクセスできない。

# sgoinfre

ネットワークストレージとして自由に活用できるディレクトリ。sgoinfreに保存したファイルはどの席からでもアクセスできる。

## ユースケース

- Born2beroot で活用するVMのイメージの保存場所（VDIファイルなど）
- Inceptionで活用するコンテナイメージの保存場所

## sgoinfreとgoinfreの使い分け

どのLinuxからでもアクセスできるようにする場合は、sgoinfreを活用してください。読み込み書き込みスピード重視の場合は、goinfreを活用してください。

## 活用方法

ホームディレクトリ上の `sgoinfre`

と `goinfre`

ディレクトリにアクセスしてから、ファイルの操作などを実施してください。
