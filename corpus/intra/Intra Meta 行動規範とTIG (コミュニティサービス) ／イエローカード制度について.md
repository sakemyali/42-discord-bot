# Intra Meta 🚯 行動規範とTIG (コミュニティサービス) ／イエローカード制度について

## 行動規範とTIG (コミュニティサービス) の目的

行動規範とTIGのリストは、学生のみなさんが42 Tokyoのコミュニティにとって悪影響を与えないために規定されています。

これはカリキュラムの一つであり、42 Tokyoのコミュニティを健全に保つため、また学生たち自身が安全に学習を進めるためにも必要なことです。

Association42ではTIG（コミュニティサービス）の目的について以下としています。

```
The goal is for the student to give back some time to the community. It should be useful actions but also boring actions, so the student try to not make the same mistake again.
- Handbook pedago 42 より引用
```

行動規範を違反した場合は、学生本人がTIG（コミュニティサービス＝奉仕活動）を行うことで42東京のコミュニティに時間を還元します。

これにより、また同じ違反を繰り返さないようにすることを期待されています。

これらの目的を理解したうえで、行動規範の遵守をお願いします。

## 行動規範を違反したら…

行動規範の違反はスタッフにより指摘されます。即座にIntranetの利用が制限されるため、あなたのメールボックスを確認し、TIGの日程を指定してください。

指定したTIGの時間帯は学習を進めることができません。また、TIGを行わずに学習を進めることもできません。

どのようなコミュニティーサービスを行うかについては、当日スタッフによりDiscordで案内されます。

## 行動規範とTIG（コミュニティサービス）のリスト

これらのルールは完全なリストではなく、一部のTIGはスタッフメンバーの裁量に委ねられています。

複数回の違反は、より重いTIG(コミュニティサービス)または退学となる可能性があります。

## イエローカード制度について

不正や問題が発見された場合、あるいは通報を受けた場合、42Tokyo運営事務局は調査チームを立ち上げ、事実確認を行います。

調査チームは外部の弁護士や労務専門家、内部監査の専門家によるものです。多面的な調査を行い、慎重に検討を重ねた上で判断を決定いたします。

当然ですが、片方の当事者からの証言、意見だけで判断することはありません。当事者の申し立てもお受けします。

調査チームによって不正や問題の事実認定がなされた場合、懲罰委員会を設置します。懲罰委員会には、問題の当事者や利害関係者は加わることはできません。

この仕組みは、一般的な会社でも採用されている手続きに則っており、社会通念から著しく乖離したものではありません。

イエローカード制度は、42の基本方針をもとに運用され、チート行為、他人への攻撃、いじめ行為、パワハラ、セクハラなど、度を超えたと判断された場合にイエローカードが提示されます。

事実に基づかない噂話や類推による流言や誹謗中傷、過度な詮索なども懲罰の対象になりますので、ご注意ください。

イエローカードを累積2回提示された方は退学処分となります。そのため2回目の提示は法的な確認なども含めて、かなり慎重に行っております。

また、イエローカードによる、よらないに関わらず、退学者に関する情報も個人のプライバシーに関わることなので公表いたしません。

1回目のイエローカードは注意喚起の意味もあります。1回出されたものの、その後反省され、現在ご活躍されている方も数多くいらっしゃいますので、そのように考えて下さい。

以下の行為を行った学生に対し、イエローカードを提示します。

- チート行為などの不正を行ったと判断された場合。
- 修学や就業環境を著しく害する行為、その他社会通念上悪質性が高いと判断される行為を行った場合。

- イエローカードが累積2回提示された方は退学処分にします。
- 学生等から報告があった事例について、イエローカード提示の可能性が考えられる場合は、行為者、被害者の両名および関係者にヒアリングを実施いたします。
- ヒアリングの結果、複数の視点からイエローカード相当の事例が発生したことが確認された場合、懲罰委員会で最終的に審議し、提示有無を決定いたします。
- 決定後、提示された本人にのみ、提示されたことを通達いたします。
- 但し、悪質性が極めて高いと判断された場合は、イエローカードを掲示せず直接退学処分となる場合もあります。

## 「当事者の不服申し立て」への対応について

前提：

①学校教育法にて、退学処分を含めた懲戒について、学校に幅広い裁量権を認められています。

②ただし学校における懲戒は一般企業等団体内部の規律保持のためにするものとは異なり、「教育上の必要がある」ときに行われ、教育作用の一環としても捉えられています。

③退学処分は他の懲戒処分とは異なり、生徒を学外に排除するという最終的手段を用いた重大な処分であるため、最も慎重に行われなければならないと考えています。

学校教育法施行規則二十六条三項は退学処分の事由として、次の四個をあげています。

```
一、性行不良で改善の見込みがないと認められる者
二、学力劣等で成業の見込みがないと認められる者
三、正当な理由なくて出席常でない者
四、学校の秩序を乱し、その他学生又は生徒としての本分に反した者
```

イエローカード制度に関しては、上記に基づき制度設計されており、上記要件を満たす形で整備しております。

皆さんのご理解の通り、ピアラーニングを主軸に運営していることもあり、自己都合含めて退学される学生が発生してしまうことは、事業運営上の損失になるとの認識は相違ございません。

そんな想いを反映すべく、通常の学校規則よりも「失敗を許容」出来るような制度として、イエローカード（注意）という形で教育的観点から学生の成長を期待するという想いを反映させました。

一方で、イエローカードを累積してしまった学生に対しては、学校運営における秩序や他学生の学ぶ権利を阻害することから、厳格な対応を取らざる得ないため、第3者委員会とともに慎重に議論を重ね決まった処分を通知することとしています。

もちろん、退学処分の確定事項に対して不服とする本人または利害関係人は十分な反証を有する場合、または相当な理由があると認められる場合に限り、本人への通知後委員会に対して再審査を請求することができます。

ただし、最終的に本人が納得しているか否かではなく、慎重公正を期して委員会が審議にあたり、懲罰委員会が処分を決定することになります。この点は、他の高校、大学の退学処分と同じです。

我々は、本人が反省し前進するために退学処分を通知していると認識しており、退学処分という重たい処分を受けてそれと向き合うことが社会教育上、学校が取るべき責務だと考えています。

またイエローカードを出した対象者、理由、関連する詳細事項については、当該学生や関係する学生の今後の仕事や人間関係への影響を最小限に留めるため、学生の将来を考慮し、あえて公表しないこととしています。

一度、証拠を公表されるとデジタル上は半永久的に残りますから、当事者の将来の為にも、プライバシーを守ってあげたいと思っています。そして心から反省し、己を磨き成長し、笑顔で話ができる日が来ることを切に祈っております。
