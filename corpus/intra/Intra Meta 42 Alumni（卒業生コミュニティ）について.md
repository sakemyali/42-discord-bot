**Alumniとは**

Alumniは、英語で「卒業生」「同窓生」という意味です。

42では、Common Coreを修了し、42での学習を終了した世界中の42キャンパスの卒業生を指します。

Alumniになると、Intranetのアカウントに「You're now an alumni!」と表示されます。

**Alumniの条件／特典**

Alumniになることで、42での学習を終了した学生が、42コミュニティの一員であり続けることができます。

Alumniコミュニティに参加することで、42alumni.org プラットフォームへアクセスできる権利や、世界中の42コミュニティと関われるなど、特典を得ることができます。

**Alumniになるための条件**

Alumniになるためには、Common Coreを修了する必要があります。

Common Coreを修了した学生のIntranetには、 **”Alumni Launchpad” **（Alumniになることを決定するボタン）が表示されます。

**重要事項**：

- 42での学習を終了し、Alumniになることを選択した場合、この決定は
**取り消すことができず**、42でのレベルが永久に凍結されます。したがって、慎重に検討をしてください。個人的な目標に達するまで、42での学習を続けることを推奨します。

**注意事項**：

将来42の海外キャンパスでRNCPの取得を目指したい場合、Alumniになることを選択せずに、現役学生のステータスでいることを推奨します。

**Alumniになった後のキャンパス変更はできません。**RNCP取得に必要な追加プロジェクトに取り組む場合、Alumniとしてよりも学生としてそのプロジェクトを完了する方が簡単です。

学位取得コース（RNCPなど）を受講している場合は、Alumni Launchpadボタンを押す前に、ディプロマを取得してください。

42カリキュラムの中で、企業プロジェクト（インターンシップなど）に登録している間は、Alumni Launchpadボタンを押すことはできません。

```
＊学位取得コース・企業プロジェクト（インターンシップなど）は、一部キャンパスのみで登録できるカリキュラムです。現在、Tokyoキャンパスではこれらのカリキュラム提供を行っていません。（2024年4月現在）
```

**Alumniになるメリット（特典）**

**生涯にわたって42のIntranetにアクセスできます。**個人的な技術向上のために、42のカリキュラムに取り組むことはできますが、経験値（XP）は獲得できなくなり、レベルをあげることはできません。

**限定イベントに参加できます。**Alumni Gala (Gala = 祭典) 、アフターワークス、カンファレンス、ハッカソンなど

**42 Alumni向けの求人情報にアクセスできます。****Alumni専用のプラットフォーム 42 Alumniで、42のグローバルなAlumniコミュニティに参加できます。**世界のどこにいても42の仲間とつながることができます。関心のあるトピックについて話し合ったり、42の最新ニュースをフォローしたり、様々なイベントを企画したり、求人情報への投稿・応募など、様々な交流ができるオンラインプラットフォームです。

**世界中の42キャンパスにアクセスできます。**（各キャンパスの規定により異なります。詳細はこちら）**42のショップで、Alumniのための限定グッズを購入できます。**42限定グッズ（Tシャツ、トレーナー、キャップ、ソックスなど）が欲しいAlumniのためのオンラインショップです。新商品は定期的に追加されます。 Alumniアンケートに回答すると、ショップで使用できる個人割引コードが発行されます。

**公式な42の証明書（Alumniになった時点の最終到達レベル証明書）とバッジを獲得できます。**Alumniになると（またはRNCPを取得すると）、デジタルクレデンシャルの世界的なプラットフォームCredlyで、いつでも42の証明書とバッジを発行することができます。

**学生メールアドレス（@student.42tokyo.jp）が保持されます。**Alumniではない場合、Intranetが数年間使用されないと、EU-GDPRにより消去される可能性があります。

**グローバルな42born2codeのSlackにアクセスする権利を維持できます。**＊閉校したキャンパスのAlumniには適用されません。

**42 Alumniネットワークの規模**

2023年3月時点で、42には3,000人以上のAlumniがいます。

**Alumniになる方法／自動Alumni化システム**

**Alumniになる方法**

Alumniになるには、2つの方法があります。

**1. Common Coreを修了後、自らAlumniになる手続きを行う。**

**2. 42 Networkの規定による『自動Alumni化』システムにより、自動でAlumniになる。**

**42で学習を続けている場合（42 Advancedカリキュラム）**Common Coreを修了した後に表示される "Alumni Launchpad" から手続きをすることで、いつでもAlumniになることを選択できます。 （ 詳細はこちら） https://profile.intra.42.fr/alumni

**⚠️ 注意 ⚠️ Alumniになる選択を決定した後、取り消しはできません。42でのレベルは永久に凍結されます。**

**42の学習を休止している場合**Common Core修了後から

**8ヶ月間XP（経験値）を獲得しなかった場合、自動的にAlumniになります。**＊XPを獲得していない学生へ、事前に42 Networkからメールで通知が届きます。

XPを獲得し、学習を継続している場合でも、Common Core修了後から4年半（4年6ヶ月）経過後、自動的にAlumniになります。

```
＊Alumni資格に該当しない場合、Alumni LaunchpadはIntranetに表示されません。（例：Common Coreを修了していない、Blackholeになっている など）
```

**『自動Alumni化システム』について**

Common Core修了後、**8ヶ月間XPを獲得していない学生が自動的にAlumniになるシステム**です。

Advancedカリキュラムで活動し続ける（＝Alumni化を避ける）ためには、XPを獲得する必要があります。自動Alumni化のルールは全キャンパス共通です。

XPを獲得している（学習を継続している）学生でも、**Advancedカリキュラムの最長在籍期間は4年半（4年6ヶ月）**です。

**2024年4月〜導入時のタイムライン**

このシステムは、2024年4月15日より導入されます。（全キャンパス共通）

**現在Advencedカリキュラムに在籍しているすべての学生が「自動Alumin化が実装される日（2024年4月15日）にCommon Coreを修了した」とみなされます。**

**2024年4月15日**：Common Core修了済みの全学生に対して、自動Alumni化のカウントダウンが開始。**2024年12月15日**：8ヶ月間XPを獲得しなかった学生が、自動でAlumniになる最初の日付。

**警告メールについて**

🟠 **活動停止4ヶ月後（XPを獲得していない学生への通知）**

⇒対象学生に、最初のリマインダーメール（英語）が送られます。

🔴 **活動停止7ヶ月後**

⇒ 自動でAlumniになる日が間近に迫っていることを知らせる2回目のリマインダーメール（英語）が送られます。

🎓 **活動停止8ヶ月後**

⇒自動的にAlumniとなり、メール（英語）で通知されます。レベルは永久に凍結されますが、42のプロジェクトに取り組むことはできます。

＊メールは英語のみで送信されます。

**Alumniになった後、42で何ができますか？**

**Alumniになった後も、引き続きキャンパスを利用できますか？**

42 Tokyoでは、Alumniになった後もキャンパスで学習することができます。ただし、**42 Tokyo学生用の入館カード（セキュリティカード）を返却してもらう必要があります。**

Alumniになった後、キャンパスを利用する時は、スタッフから一時的に貸与する「ゲスト用貸出カード」を受け取ってください。

＊貸出時に指定された日時までに、貸出カードを返却してください。

＊スタッフの不在日時に来校された場合、キャンパスの利用はできませんのでご注意ください。

**Alumniとして、キャンパス内では何ができますか？**

生涯にわたって42のプロジェクトを学習することができます。ただし、経験ポイント（XP）の獲得はできなくなります。

学生のプロジェクトをレビューしたり、他の学生やAlumniから自分のプロジェクトをレビューしてもらうことができます。レビューを行う学生とAlumniは、同じキャンパスに所属し、レビュー中は両者が物理的にキャンパスにいる必要があります。

ゲーミフィケーションへのアクセス：Achievements、Wallet、称号、Coalition

Intranet上のイベントへの登録・参加（＊各イベントの参加条件によっては参加できない場合があります。）

学生メールアドレス（@student.42tokyo.jp）が保持されます。

＊注意：重要なアカウント（GitHub、クラウドプロバイダーなど）は、Alumniになった数ヶ月後に個人メールに移行することを強くお勧めします。

＊閉校したキャンパスのAlumniには適用されません。

**海外の42キャンパスへのアクセス方法は？**

Alumniとして海外の42のキャンパスに訪問したい場合、訪問の詳細（キャンパス、期間、目的）をalumni@42.frまでメールしてください。折り返し連絡が届きます。

キャンパス一覧はこちら： https://www.42network.org/42-schools

一部のキャンパスでは、Alumni専用のスペースが設けられています。

**Alumni FAQ**

**Alumniになりたくない場合はどうすればいいですか？**

自らAlumniになることを選択した場合や、自動的にAlumniになった場合、元に戻すことはできません。

Alumniになりそうだが、プロジェクトを終了させたい場合（個人的な事情がある場合）：事前に所属キャンパスのスタッフに相談してください。その後、個別に対応を判断します。

**同意なしにAlumniにされてしまいました。元に戻すことはできますか？**

Alumniになった後、元に戻すことはできません。

**Blackholeになった場合、Alumniになれますか？**

Blackholeになった後、Alumniになることはできません。

**Alumniになった後、キャンパスを変更できますか？**

Alumniのキャンパス変更は許可されていません。

**AlumniでもTIGになりますか？**

AlumniでもTIGの対象になります。学生と同じように、キャンパスのルールによって、Intranetや校舎へのアクセスができなくなる可能性があります。

**Alumni Launchpadとは何ですか？どのように機能しますか？**

Alumni Launchpadは、Intranet上のツールです。

学生からAlumniへのステータス変更を正式に行うために、手動で起動する必要があります。

Common Coreを修了したら、いつでもAlumni Launchpadを起動することができます。

Intranetで自分のloginをクリックし、メニューから「Settings」→「Alumni」を選択してください。

またはhttps://profile.intra.42.fr/alumniにアクセスしてください。

**注意：これは取り消し不可能な手続きです。**Alumni Launchpadで手続きを行うと、Alumniステータスを確認するメールが届きます。「Alumniアンケート」に回答し、特典を有効にしてください。

特典を有効にすると、特典にアクセスするための3通のメールが届きます。

a. Alumniプラットフォーム 42alumni.org

b. 42 Alumni Shop ＊個人割引コードが付いてきます。

c. Credly - 42の証明書とバッジを取得するためのプラットフォーム

**Alumniアンケートとは何ですか？**

Alumniになると毎年職業状況についてのアンケートにご協力いただきます。この結果は、教育学的な証明に使用され、42 のカリキュラムを学生や就職市場の期待に沿うように維持するのに非常に役立ちます。

また、一般的な統計（就職率など）も、42 コミュニティで共有されます。

Alumniアンケートにご協力いただいたお礼として、42Alumniショップで使用できる個人割引コードを差し上げます。

**AlumniとしてRNCP資格を取得するには、どのような手続きが必要ですか？**

RNCP資格を取得したい場合、現役学生である時（Alumniになる前）に、RNCP資格を取得できるキャンパスに転校する必要があります。

＊Tokyoキャンパスでは、RNCP資格を取得できるカリキュラムを提供していません。

詳細は、以下のページよりご確認ください。

What is the process to obtain a RNCP certification as an Alumni?

**Credlyとは何ですか？どのように機能しますか？**

Alumniになると（またはRNCP認定（42が提供）を取得すると）、デジタルクレデンシャルの世界的なプラットフォームCredlyで、いつでも42の証明書とバッジを発行することができます。

これは、あなたが42で最後に到達したレベルを証明するものです。（注意：卒業証書ではありません。）

この証明書とバッジは、LinkedInやFacebookなどのソーシャルメディアへの共有だけでなく、URLを企業に共有すると、企業がその真正性を確認することができます。

**仕組み**

1- Alumniになると（または42が提供するRNCP認定を取得すると）、Credlyで証明書・バッジを発行するためのメールが届きます。＊発行は任意です。

2- Credlyでアカウントを作成。情報は42のIntranetアカウントから自動的に取得されます。

3- Credly上で、いつでも証明書・バッジを発行することができます。最終レベル＋RNCPなど、複数のバッジを所有できます。

**Intranetアカウントにアクセスできなくなりました。**

3年以上Intranetにログインしていない場合、一般データ保護規則（EU GDPR）に従い、Intranetのアカウントが消去されている可能性があります。その場合、残念ながらアカウントを復元することはできません。

ご不明な点がございましたら、alumni@42.fr までメールにてお問い合わせください。

**グローバルSlack「42born2code」にアクセスできません。**

一般データ保護規則(EU GDPR)により、あなたのIntranetアカウントが消去され、'42born2code' Slackから削除された可能性があります。再登録を希望される場合は、alumni@42.fr までご連絡ください。

**個人情報はどうなりますか？**

あなたがAlumniになると、EUの一般データ保護規則(GDPR)に従い、42があなたに関するデータを保有していることを知らせるメールが毎年届きます。あなたからのアクションがない限り、そのデータは保有され続けます。

＊ご自身のデータ処理に関する権利をいつでも行使することができます： https://signin.intra.42.fr/legal/terms/5

＊データの消去リクエストは、当社のすべてのサービスに関係します。**データ消去後は、Alumniの特典を受けることができなくなります。**
